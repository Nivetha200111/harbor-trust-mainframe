All input rows are deterministic and synthetic. Files in `ascii/` are 160-byte fixed records with LF delimiters. Corresponding `ebcdic/` files were transcoded with IBM-037 and contain concatenated 160-byte records without text line delimiters. Each account, transaction, check, and loan fixture contains 1,200 records; FX has 1,200 rows. `scripts/generate-fixtures.py` regenerates both encodings.
